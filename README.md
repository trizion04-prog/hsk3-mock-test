# Science Quest

Cambridge Primary Science practice app (Stages 1-6) with answers, explanations, coins, leaderboards and a teacher dashboard. Runs on Firebase (Firestore + Hosting).

- `public/index.html` is the built app. Rebuild it from `src/` with `python3 src/build.py public/index.html '<firebase config json>'`.
- Deploy: `./deploy.sh` (Google Cloud Shell works well).
